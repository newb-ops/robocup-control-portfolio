# 공개본 확인

검사일: 2026-09-13

Python 32개 파일의 구문 검사와 원본 대비 실행 AST 비교를 통과했습니다. 주석과 설명 문자열을 제외한 실행 코드는 원본과 같습니다. XML/URDF 3개 파일의 파싱과 원본 구조 비교도 통과했습니다.

`competition/selftest.py`는 네트워크 연결을 차단한 상태에서 통과했습니다. 가상 입력에서 `SEARCH → TRACK → APPROACH → AIM → KICK → COOLDOWN` 전이를 확인했고 종료 시 구동 명령은 `(0, 0)`이었습니다.

포함한 ONNX 모델은 원본 SHA-256과 일치합니다. 공개 파일의 개인정보·자격 증명 패턴 검사와 문서 상대 링크 검사도 통과했습니다.

실제 ROS 빌드와 카메라 추론, 로봇 구동, Gazebo·MuJoCo 시뮬레이션은 이번 공개 작업에서 재실행하지 않았습니다. 기존 프로젝트의 실물 운용 경험과 이번 파일 검사는 구분합니다.
